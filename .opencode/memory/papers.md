# Memory: papers

Persistent reading list + takeaways. **Append-only.** Cite source.

## Whisper
- Radford et al., 2022. "Robust Speech Recognition via Large-Scale Weak Supervision."
  https://arxiv.org/abs/2212.04356
  - Takeaway: strong multilingual zero-shot; fine-tuning helps low-resource langs.

## wav2vec2 / XLS-R
- Baevski et al., 2020. "wav2vec 2.0." https://arxiv.org/abs/2006.11477
- Babu et al., 2021. "XLS-R." https://arxiv.org/abs/2111.09296
  - Takeaway: CTC fine-tuning effective for low-resource with limited labeled data.

## SpecAugment
- Park et al., 2019. https://arxiv.org/abs/1904.08779
  - Takeaway: time/freq masking + speed perturbation are cheap, reliable gains.

## MMS
- Pratap et al., 2023. "Scaling Speech Technology to 1,000+ Languages."
  https://arxiv.org/abs/2305.13516
  - Takeaway: covers many low-resource languages; relevant for WAXAL.
